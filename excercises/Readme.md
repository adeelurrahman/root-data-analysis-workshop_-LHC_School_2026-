# Tutorial exercises

Work through the macros in numerical order from this directory. All code, inputs, plots, and ROOT files are kept together in this directory. Files for one lesson share the same `tutorialNN_` prefix.

For example:

```bash
root -l tutorial01_random_numbers.C
root -l tutorial02_first_histogram.C
```

The questions at the end of each macro are part of the exercise. Change one setting, predict the effect before running, and then compare the result with the prediction.
